# 職人原価計算（PWA）

素材の値段と売値を入れるだけ。もうかるか、素材は何Gまで買っていいかが一目でわかります。
端末の中だけで動き、通信もサーバーも要りません。

## 使い方
1. ★3・★2・★1 の売値を入れる（「8.8万」のような書き方もそのまま読みます）
2. つまみで★の出やすさを合わせる。赤い斜線の範囲は「そこまでしか★3が出ないと赤字」
3. 素材と単価を入れる。素材ごとに「上限まであと何%」が出ます
4. つくった結果を記録していくと、自分の実際の出方に置きかえられます

## 中身
| ファイル | 役目 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて内蔵） |
| `manifest.webmanifest` | アプリとして入れるための情報 |
| `sw.js` | オフラインで開くための仕組み |
| `icon-*.png` | ホーム画面のアイコン |

## ホーム画面に入れる
`index.html` を直接開いても全機能使えますが、アプリとして入れるにはHTTPSでの配信が必要です。

1. 5つのファイルを同じ階層に置いたまま公開する（GitHub Pages / Netlify / Cloudflare Pages などで十分）
2. スマホのブラウザでそのURLを開く
3. Android(Chrome)：「ホームに追加」ボタン、またはメニューの「アプリをインストール」
   iPhone(Safari)：共有 → ホーム画面に追加

一度開けば、次からは機内モードでも起動します。

## 前提の数値
旅人バザーは「出品1回10G」「売れた額の5%が手数料」で計算しています。変わったら設定欄で直してください。
保存先は端末の中だけです。機種を変えるときは書き出してください。
