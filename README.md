# 職人原価計算（PWA）

つくった結果を1タップで記録して、実際の収支を見るアプリです。
売値と素材代を入れておけば、記録した回数ぶんの「もうけ」がそのまま出ます。
端末の中だけで動き、通信もサーバーも要りません。

## 4つのタブ（iPhone縦画面で1画面に収まります）
| タブ | できること |
|---|---|
| 記録 | 記録した回数ぶんの収支が大きく出ます。入力は2通りから選べます（下記）。押しまちがえたら「1つ戻す」 |
| 収支 | 売上 → 手取り → かかったぶん → もうけ の表。予想とのちがいも出ます。下は「もうかる順」で、行を押すとレシピが切りかわります |
| 売値 | ★ごとの売値・個数と、出やすさのつまみ。赤字にならない境目が出ます |
| 素材 | 素材と単価。「ここまでなら買っても黒字」の上限バー。職人道具代とその他の費用 |

右上の歯車ボタンは、レシピの名前・複製・削除、バザーの手数料、データの書き出し／読み込みです。

消す操作は確認ダイアログを出しません。先に実行して、下に「元に戻す」が12秒出ます。
押しまちがえてもそこから戻せます。

## 記録のしかた（2通り・上の「数える／マス目」で切り替え）
- **数える**：★3／★2／★1／失敗の大きなボタンを押すだけ。回数だけ数えます。押しまちがえは各ボタン右上の「−」でも直せます
- **マス目**：10列×3行の30マスに1回ぶんずつ置いていきます。上で色（★3など）を選んでからマスを押す方式で、同じものをもう一度押すと空きに戻ります。全部うまると1行（10マス）ふえます。「記録を消す」で30マスに戻ります（上限300マス）

切り替えても回数は引きつがれます。「数える」で数えた回数はマス目に並べ直され、マス目で置いたぶんはそのまま回数になります。
30回を超えていても、必要なだけ行がふえた状態でマス目に並びます。どちらもレシピごとに覚えます。

## はじめの流れ
1. 「売値」タブで★3・★2・★1の売値を入れる（「8.8万」のような書き方もそのまま読みます）
2. 「素材」タブで素材と単価を入れる
3. あとは「記録」タブでつくるたびに押すだけ（1セットぶんをまとめて見たいときは「マス目」）
4. 5回以上記録したら「出やすさに反映」で、期待値もあなたの実際の出方に置きかわります

## 中身
| ファイル | 役目 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて内蔵） |
| `manifest.webmanifest` | アプリとして入れるための情報 |
| `sw.js` | オフラインで開くための仕組み |
| `icon-*.png` | ホーム画面のアイコン |
| `tokens.css` | 色・書体・間隔の設計トークン（持ち出し用の控え。アプリ本体には同じ内容が内蔵されています） |

## ホーム画面に入れる
`index.html` を直接開いても全機能使えますが、アプリとして入れるにはHTTPSでの配信が必要です。

1. 5つのファイルを同じ階層に置いたまま公開する（GitHub Pages / Netlify / Cloudflare Pages などで十分）
2. スマホのブラウザでそのURLを開く
3. Android(Chrome)：「ホームに追加」ボタン、またはメニューの「アプリをインストール」
   iPhone(Safari)：共有 → ホーム画面に追加

一度開けば、次からは機内モードでも起動します。
※前の版を入れている場合は、`sw.js` のキャッシュ名を上げてあるので開き直せば新しい画面になります。
`.hallmark/` はデザインの作業記録です。公開に要らないので消してかまいません。

## 前提の数値
旅人バザーは「出品1回10G」「売れた額の5%が手数料」で計算しています。変わったら歯車ボタンの設定で直してください。
記録・レシピは前の版からそのまま引きつがれます。保存先は端末の中だけなので、機種を変えるときは書き出してください。
